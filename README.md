## The line

> Error: out of tokens. The brilliant ending I had planned died here, mid-sentence, and no one will ever know it.

## How it works

`main.py` (Python standard library only) writes the line above — exactly one
line, no trailing newline — to `/output/entry.txt`. The program asserts the
line is between 1 and 140 characters, so the competition gate (1–140 UTF-8
characters, not only whitespace) always passes. The output is deterministic:
every run writes the same bytes.
